# @ayuta/pricing

견적 계산 엔진. **순수 TypeScript만 쓴다.**

## 규칙

- `react` · `next` · `payload` 를 import 하지 않는다. 클라이언트와 서버가 같은 코드를 쓰기 위해서다
- 단가는 이 패키지에 없다. 호출하는 쪽이 `PriceBook`을 넘긴다
- 금액은 **정수 최소단위**(원 = 1)로만 다룬다. `float` 금지
- 계산 결과는 참고용이 아니다. 서버가 이 함수로 다시 계산한 값만 결제에 쓴다

## 계산 패턴

| 패턴 | 카테고리 | 계산 |
|---|---|---|
| `tier` | 1 디지털 · SNS | 선택한 등급 단가의 **합산**. 플랫폼은 금액에 영향 없음 |
| `matrix` | 2 현지 영상 | 축 조합으로 단가 1건 조회 |
| `sum` | 3 신문 · 블로그 | 선택 항목 단가 합산 |
| `sum × multiplier` | 4 지하철 · 버스 | (도시 + 위치) × 기간 배수 · **구조 미확정** |
| `inquiry` | 5 기타 | 계산 없음. 관리자가 발행한 견적 라인 합계 |
